# CraftPilot 0.11.0-alpha

- Own Camping tab with Campfires, Buffs, and Objects & Upgrades; all twelve professions or the selected profession.
- Three fire sizes, 37 faction-filtered reference objects, expandable buff level ranges, class-buff exclusions, recipe sources, materials and missing quantities. Missing current boss/drop data remains unknown.
- Automatic German/English interface, with English fallback for other client languages; client recipe names and available spell text take priority.
- Explicitly drawn size/position sliders and on/off sliding switches in settings.
- Pinned camping source manifest, original notices, focused importer and automated tests.

The camping reference is build 1.60.1.70425, generated 2026-10-16; it is not a verified current-live database. Trapper's Workbench is an additional guide-only hint without recipe or buff data. See the included `docs/CAMPING_SOURCES.md` for scope and validation.

Install the ZIP's `CraftPilot` folder into `Interface/AddOns`. Existing plans and recipe scans are retained. Automated checks pass locally; in-game layout, skin compatibility and server behavior still need a Forever-client test.
