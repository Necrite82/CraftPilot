# CraftPilot 0.17.0-alpha

- Include eligible unlearned trainer recipes in Now skilling and Smart Skilling. Compare material purchases plus a one-time learning fee against learned recipes. Lower upfront spending is prioritized in the Now view. Missing/guessed fees cannot claim a saving. Native unlearned records without materials may use explicitly referenced catalogue ingredients; learned records with missing materials still do not fall back.
- Display a suitable trainer waypoint directly beneath the proposal, without another menu. Prefer the current map and compare distances only on the same map. Honor explicit restricted trainer lists, faction, learning skill, known level gates and specialization/reputation restrictions. General profession-trainer matches are candidate destinations, not proof of the current recipe offer.
- A comparison batch targets about five expected points at current colour and charges learning once. This is an estimate at the current colour, not a future five-level simulation; colours can change, travel and new tools are not priced. Smart Skilling also shows a gold shortfall where the wallet amount is available. Unknown stock/price data keeps savings uncertain.
- The existing recipe-view button cycles Useful recipes / Unlearned / All recipes. All includes inactive learned recipes, other learning sources and future recipes present in the available catalogue/client snapshot, greyed out with required skill. Reference rows never become learned plan steps or zero-cost crafting recommendations. This is not a complete live-game recipe database.

Validation: full Lua suite, unlearned recipes without native ingredients, one-time fees, high fees reversing savings, unknown/guessed fees, same-map teacher selection, future grey rows and learned-state transitions; bilingual views and exact install-archive verification. No new datasets or external implementation imported. Current trainer offers and UI rendering are not claimed as independently observed by these automated tests.
