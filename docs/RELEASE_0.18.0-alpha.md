# CraftPilot 0.18.0-alpha

- Replace appended recipe price/inventory paragraphs with labelled purchase, net-AH-output and vendor-output metrics. Consumed stock units are separate from full per-item inventory, which remains visible in the tooltip and tables. Wrapped titles, details and notes reserve their measured height.
- Rebuild the cost popup as a dashboard: material purchases, one-time learning and PAY NOW are prominent; economic cost is separated from cash, followed by output unit-sale values and material requirements. Material, Need, Bags, Bank, Buy, AH/unit and purchase-cost columns align consistently. Shortages sort first, then item name. Unknown bank/prices and stale AH quotes remain marked.
- Profession shopping, camping shopping and material views share the same inventory table. Native item icons and currency icons remain visible. Game-provided output hyperlinks/spell/item tooltips are used first and CraftPilot appends a labelled cost and stock section; no global tooltip hooks or protected crafting calls are added.
- Move Report a bug out of Settings to the bottom directly after the version, accessible from every view.
- Add + Shopping list on a selected actionable recipe and Add missing materials in the cost popup. Adds current one-craft/context shortages as explicit personal purchase quantities; it does not change profession plans.
- Personal shopping window: input an item name that the client can resolve, an item link or ID, set a whole quantity, click an existing row to edit, remove with the close icon, and send exact quantities to Auctionator. Zero removes a position. Repeated recipe additions accumulate current shortage snapshots; they are not an automatically netted multi-recipe production plan and do not decrement automatically after buying. Use the profession plan for shared-stock/intermediate accounting.

Validation: full Lua regression suite, aligned stock columns within container widths, shortage values, long-text layout spacing, native-tooltip-first behavior, manual list isolation/add/edit/remove, exact-quantity Auctionator export without double stock subtraction, footer report placement, bilingual view construction and exact install ZIP equality. Existing recipe pricing/routing logic and imported datasets are unchanged. In-game rendering and UI-replacement interaction still depend on the actual client; automated widget checks are not a newly observed live-game screenshot.
