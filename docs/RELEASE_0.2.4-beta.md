# CraftPilot 0.2.4-beta – neuer Ordnername

Ein anderes Addon nennt sich seit Kurzem ebenfalls „CraftPilot“ und nutzt denselben Ordner, dieselben gespeicherten Daten und denselben Befehl. Damit beide nebeneinander funktionieren, heißt CraftPilot intern jetzt **CraftPilotPro**. Im Spiel heißt es weiter CraftPilot.

**Was sich ändert:**
- Addon-Ordner: `Interface\AddOns\CraftPilotPro` (ein alter Ordner `CraftPilot` von CraftPilot kann gelöscht werden; die CurseForge-App erledigt das beim Update selbst)
- Befehl: **`/cpp`** (oder `/craftpilotpro`) statt `/cp`
- Gespeicherte Daten: neu angelegt – Einstellungen einmal setzen und jeden Beruf einmal öffnen, damit CraftPilot die Rezepte wieder einliest

Alles Weitere aus 0.2.3-beta bleibt: Endgame, neue Oberfläche, eigener Rezeptkatalog, Spartipp, Discord-Link (https://discord.gg/DpsBkHtQS).

**Voraussetzungen:** QuestieDB (Pflicht), Auctionator (empfohlen), TomTom (optional).
