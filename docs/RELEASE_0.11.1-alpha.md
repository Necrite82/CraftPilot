# CraftPilot 0.11.1-alpha

- A single Settings tab replaces the duplicate Settings/Options navigation.
- Bank status and AH material-price status appear in separate columns.
- AH status follows the prices and ages for unique materials from captured recipes of the selected profession; missing or undated data never appears current.
- The footer shows the cost mode instead of a permanent price-age warning.
- Four camping blueprint drop locations added with unconfirmed live availability. Trapper's Workbench now includes materials, item/recipe information and skill-300 use requirement; its beta drop report remains marked unconfirmed. No estimated drop chance is presented.

Automated Lua and archive checks pass. In-game visual and server validation remains outstanding.
