# CraftPilot 1.0.0

CraftPilot ist fertig für alle – ohne Beta. Danke an alle, die getestet und Fehler gemeldet haben.

## Neu

- **Selbst herstellen:** Fehlt ein Material, dessen Vorstufe du hast (Erz für Barren, Stoff für Ballen …), nennen Empfehlung und Rezeptdetails sie, z. B. „bis 21 Mithrilbarren aus 21 Mithrilerz (Bergbau)“. Gezählt werden Tasche, Bank, Briefkasten und Twinks; kann ein Twink es herstellen, steht sein Name dabei.
- **Empfehlung vollständig lesbar:** Was fehlt, steht in der ersten Zeile; Twinks, Spartipp und der ganze Weg in einer zweiten.
- **Schärfere Schrift** auf den goldenen Knöpfen.
- **Seitenleiste deckend**, andere Fenster scheinen nicht mehr durch.

## Hinweis für Updates von 0.2.3

Seit 0.2.4 heißt der Addon-Ordner `CraftPilotPro` und der Befehl `/cpp`. Wer von 0.2.3 kommt: Einstellungen einmal setzen und jeden Beruf einmal öffnen.
