# CraftPilot artwork

Project-specific generated artwork: an anvil, compass and gear in brass, charcoal
and teal. Created for CraftPilot in November 2026.

- `CraftPilot.png`: transparent 512px project logo.
- `CraftPilot.tga`: transparent 128px, uncompressed 32-bit runtime texture.

The runtime package includes the TGA. The project license applies to these assets.
Game-provided profession, recipe, item and currency textures are referenced by
the addon at runtime; those game textures are not copied into this directory.
